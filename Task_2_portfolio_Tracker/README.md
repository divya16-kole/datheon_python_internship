NEBULA - Investment Portfolio Tracker
An anime-inspired desktop portfolio tracker built with Python and PySide6.
Features
Add stock ticker, buy price, and quantity
Loads sample current prices from stock_prices.csv
Calculates invested amount, current value, profit/loss, and percentage
Displays holdings and a simple performance chart
Automatically updates portfolio_summary.csv
Remove selected holdings and export the CSV snapshot
Setup
Install the GUI dependency:
python -m pip install PySide6
Run
Open a terminal in this folder and run:
python portfolio.py
Sample tickers
TCS, INFY, RELIANCE, WIPRO, HDFCBANK
The prices in stock_prices.csv are sample values for learning and testing only. They are not live market prices or investment recommendations.
